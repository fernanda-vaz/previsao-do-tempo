# Previsão do Tempo

Este projeto é uma aplicação web que utiliza APIs para fornecer dados climáticos de qualquer cidade do mundo, incluindo temperatura, condições climáticas e umidade. A interface também exibe uma imagem de fundo aleatória que muda a cada atualização da página, oferecendo uma experiência visual dinâmica e imersiva.

## Tecnologias Utilizadas

- **HTML**: Estruturação semântica e acessível do conteúdo.  
- **CSS**: Estilização responsiva e moderna, com foco na usabilidade e experiência do usuário.  
- **JavaScript**: Lógica de interação com as APIs, manipulação do DOM e atualização dinâmica do conteúdo.

### APIs Consumidas

- **OpenWeatherMap**: Fornece informações detalhadas sobre o clima com base na cidade pesquisada.  
- **Unsplash API**: Fornece imagens de fundo aleatórias para enriquecer a estética da página.

### Responsividade

- Design adaptado para dispositivos móveis, tablets e desktops, utilizando CSS Flexbox.

### Deploy

- **Deploy na Vercel**: Publicação rápida e estável da aplicação.

## Funcionalidades

- **Busca de Cidades**: Permite ao usuário pesquisar pelo nome de qualquer cidade do mundo e obter informações climáticas em tempo real.  
- **Exibição de Dados Meteorológicos**: Apresenta temperatura, descrição do clima e umidade do ar.  
- **Imagens de Fundo Dinâmicas**: Atualiza a imagem de fundo com cada carregamento da página, utilizando fotos aleatórias de alta qualidade.  
- **Interface Responsiva**: Experiência consistente e otimizada para todos os dispositivos.

## Como Executar Localmente

1. Clone o repositório:  
   ```bash
   git clone https://github.com/fernanda-vaz/previsao-do-tempo.git
   ```

2. Navegue até o diretório do projeto:  
   ```bash
   cd previsao-do-tempo
   ```

3. Abra o arquivo `index.html` em seu navegador.
